# Parking Fee Calculator

## Description
This is a basic PHP script designed to calculate parking fees for different types of users (personel, hasta) based on the number of hours they park.

## Features
- Calculates fees for personel and hasta separately.
- Handles both single-hour and multi-hour stays.
- Applies different rates for personel and hasta.

## Installation
No installation required. Simply run the script in a PHP environment.

## Usage
```php
$kisi = "personel";
$saat = 6;
echo $tutar;
```
